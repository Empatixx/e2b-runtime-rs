Everything in E2B is built from a few ideas. Read them in this order; each one uses the previous ones.

| Concept | One sentence |
|---|---|
| [Sandbox](./sandbox/) | A running microVM that belongs to one user session. |
| [Template and build](./template/) | The recipe for a sandbox, and one baked version of that recipe. |
| [Snapshot](./snapshot/) | A frozen sandbox on disk: its memory, its disk and the VM state. |
| [Lifecycle](./lifecycle/) | How a sandbox moves between created, running, paused and killed. |
| [Node](./node/) | The machine that runs sandboxes, and the orchestrator on it. |
